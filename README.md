## 🎮 Features & GTA V Installation

* **4K Textures & Details:** High-resolution interior and exterior finishes.

### Quick Install (GTA V Single Player)
1. Extract the vehicle folder to `mods/update/x64/dlcpacks/`.
2. Add the dlc entry line to your `dlclist.xml`:
   `dlcpacks:/palmetris_ebatri/`
3. Spawn the vehicle in-game using your trainer.
